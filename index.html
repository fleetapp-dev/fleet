For macOS

Run a fleet of Claude Code agents. Know which one needs you.

$brew install --cask fleetapp-dev/tap/fleet-app

Paste into Terminal, then open Fleet. Free during the preview · macOS 14+

Fleet is a native Mac app for running Claude Code agents side by side. Each agent gets a real terminal, and a status light tells you which one is working, which is done, and which is waiting on you.

Install Fleet →

Status at a glance

Three lights. You only have to watch one.

  • Needs you

    A permission prompt or a question. Fleet sends a notification, badges the Dock, and ⌘⏎ jumps straight to it.

  • Working

    Claude is reading, editing or running commands. Leave it alone.

  • Done

    Finished while you were elsewhere. It keeps blinking until you look at it.

Resume Session

Pick up any past conversation.

Fleet lists your earlier Claude Code conversations, newest first, with their titles. Search, pick one, name it, and it reopens as an agent in its original folder with the full history.

Usage dashboard

See what every agent costs.

Today's spend across all your Claude Code work, hour by hour. Below it, every agent ranked by cost, with how full its context is and how often it compacted. Click one to jump to it. ⇧⌘U

Tabs and splits

Run tests next to the agent.

⌘D splits the terminal to the side and ⇧⌘D splits it down, so a shell sits beside Claude. ⌘B hides the sidebar when you want the whole window.

What you get

Built for running many agents at once.

A real terminal, not a preview

Every agent is a tmux session. What you see is the live terminal, and quitting Fleet leaves every agent running.

Any folder, many agents

Start agents in any folder, several per repo. Separate git worktrees are there when you want them, never forced.

Sets itself up

On first launch Fleet installs its Claude Code hooks and tmux settings, and fetches tmux and jq with Homebrew if they are missing.

Updates itself

New versions arrive in the app. One click to install, and your agents keep running.

Keyboard first

Your hands stay on the keyboard.

Every shortcut can be changed in Settings, and Fleet warns you when one clashes with a macOS shortcut.

Install Fleet

$brew install --cask fleetapp-dev/tap/fleet-app
  1. Copy the command
  2. Paste it into Terminal
  3. Open Fleet — it sets up the rest

Requires macOS 14 Sonoma or later and Claude Code. Fleet installs tmux and jq for you, and updates itself.
