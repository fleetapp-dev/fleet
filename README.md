# Fleet

Run a fleet of Claude Code agents on your Mac — and always know which one needs you.

**Website:** [fleetapp.dev](https://fleetapp.dev)

## Install

```bash
brew install --cask fleetapp-dev/tap/fleet-app
```

Requires macOS 14 Sonoma or later and [Claude Code](https://claude.com/claude-code). Fleet sets up the rest on first launch and updates itself.

## Feedback

Found a bug or have an idea? [Open an issue](https://github.com/fleetapp-dev/fleet/issues).
